# 筛选配对

状态：当前实现规格，2026-10-16。读者：使用者、开发与验收人员。本文维护功能与参考边界，持续任务状态由 [ROADMAP](ROADMAP.md) 的 F04-U4 维护。

## 功能依据与范围

对照本机蛋神助手电脑版1.2.0解包前端`webui/feature-pages.js`的`breederMatchesFilters`、`breederVisibleState`、`breederCanPair`、`breederPrediction`及页面交互。该来源能说明竞品工具行为，不能证明游戏遗传机制。

- 当前展示账号自动使用已观察背包记录，不单独复制库存或增加导入／持久化状态；不做多账号合并、云同步或尚未实现的智能配窝带入。
- 公母分栏，各自按图鉴号、等级降序、个体ID稳定排序；单个双蛋组精灵只出现一次，每侧24只独立分页，数量不再受矩阵每格8只截断影响。
- 支持名称／物种／性格／蛋组／图鉴号／个体ID搜索；蛋组、全部目录性格多选；双奖牌、四种体型／声音标记多选；声音−100～100dB及身高／体重0～100%范围。
- 类别之间同时满足；性格／蛋组各自任选其一；奖牌同时满足。未采集或目录越界体型不能满足百分比条件。标记复用`pet_marks`，不将满身高当作大块头。
- 三项数值范围使用现有双头滑条：声音步进1dB，体型步进0.1%；右侧摘要显示当前范围，未限制显示“不限”。交叉拖动联动另一端，外侧端点恢复不限；支持键盘调整，提交后沿用现有筛选请求与百分比转换。
- 任一侧都可先选；默认要求已知性格一致，可关闭。只在同一账号快照内按一公一母及蛋组交集匹配，未知性别、未知或不可繁育蛋组排除。原侧显示同进化链备选，对侧显示兼容候选；筛选仍作用于两侧，已选亲本保留在原列。
- 点击已选锚点清除整组，点击已选另一方只清该方。替换亲本时移除不兼容的另一方；记录失效时提示取消。详情清除背包旧筛选后定位并打开精灵详情。

## 参考与未知

普通窝性格显示父母各30%、随机40%；同名合并为60%，这60%不包含随机部分可能再次命中该性格。未知性格归未知份额。声音沿用家园工具规则，取均值向零取整；协议0因无法区分未采集而视为未知，精灵声音只使用抓取值，蛋的手动分贝不参与亲本候选。

身高／体重仅展示各物种区间位置的父母算术均值，不称为子代必得值或遗传概率；不推定后代奖牌。母方蛋目录缺失时明确显示资料不足。学院绿窝另以家园记录为准。本页不检查实际窝位、距离和当前放置，不宣称已经配窝或仓库完整。

## 状态与失败

Python VM只读取一次账号库存快照，domain执行规则，独立鉴权GET接口转换DTO；精灵声音随宠物快照读取。Vue页面持有筛选、分页、亲本、加载和错误状态，应用壳继续持有唯一账号代次、REST鉴权与WS。无数据库迁移和新依赖。

无效范围、非法亲本／页码返回400；缺静态目录明确不可用。输入立即废弃旧响应，离页取消请求，切号清空筛选与亲本；响应再次核对uid、版本和代次。读取失败保留已提交结果并可重试；目录／数据更新后重新校验亲本。
