# 智能配窝实施规格

本轮仅研究；页面继续占位。下一轮先实现离线建议方案，再接真实家园。此文为 SpriteLens 的实现决策，竞品代码证据不等于已验证游戏规则。

## 1. 已验证的竞品行为

来源：蛋神助手电脑版 v1.1.6 解包 `webui/planner-ui.js`、`planner-core.js`。

- 候选从当前账号背包按实例 ID 去重，性别、蛋组与静态链数据富化；跨账号个体不能直接配对。
- UI 新版提供自动公母配额、手动种公数量 0–10、额外学院绿窝、锁定和替换个体；旧普通窝算法另有 5公5母、4公6母预设。不同版本逻辑不能混用成已验证游戏容量。
- 默认策略：覆盖更多蛋组=true、补缺种公=true、补缺种母=false、仅100dB=false。
- 锁定槽位保留；重算不重复使用已锁定个体。替换后重算产出，保存计划包含版本号，候选消失后清除无效锁定。
- 旧 `pairScore` 权重：优先蛋组120/组，新增蛋组45/组，新链70，启用全覆盖另加55/新增组，补缺公95×性别概率，补缺母75，交集蛋组加分上限20；图鉴序号用于稳定破同分。
- `calculateEggNature` 明确声明 `equal-father-probability`；`nestRange` 与 `layEggCouples` 同时参与配对推断，并检查家园陈旧状态。存在多个可能父本时不是确定配对。

## 2. SpriteLens 第一版范围与默认值

只给建议，不发游戏指令。按账号独立计算，当前账号默认参与；历史账号仅可作为独立方案查看。

| 参数 | 默认 | 规则 |
|---|---|---|
| 建议槽位 | 5 对 | 明示为规划容量，可调1–10；真实窝数量单独显示 |
| 每槽 | 1公1母 | 不推断共享范围或一公多母；扩展待真实协议验证 |
| 蛋组覆盖 | 开启 | 兼容候选的已知蛋组交集 |
| 补缺种公 | 开启 | 当前账号缺少已知可产公链时优先；未知性别比例不加此分 |
| 补缺种母 | 关闭 | 可开启；未知比例同样不能算确定产母 |
| 仅100dB | 关闭 | 开启要求声音实际值==100，不能用显示百分比 |
| 优先蛋组 | 空，最多2组 | 与蛋组筛选同一目录 |
| 锁定 | 空 | 每槽整体锁定；失效锁保留警告，不静默替换 |
| 备用组合 | 每槽最多3组 | 排除其他已用个体；替换预览明确覆盖得失 |

## 3. 输入、输出与算法

独立 `domain/breeding_planner.py`：纯函数，零持久化/HTTP；`services/breeding_planner_service.py` 聚合版本和账号数据。宠物实例身份使用 `(uid, gid)`，不能以名字、物种 ID 或 actorId 替代。

输入：`uid`、宠物快照版本、目录版本、候选数组（gid/baseId/gender/nature/eggGroups/voice/chainKey/breedable/genderRatio）、目标、配置、锁定槽、可选家园证据。目录链以稳定物种 ID 集合归一，不以中文名字归并。

候选准入：已知公母性别、breedable!=false、非“未发现”蛋组、已知有效蛋组交集。breedable未知或链缺失的候选进入“资料待补”，不作为可靠推荐。数据陈旧或个体不在最新库中时不可锁定。

计算：

1. 校验所有锁定槽：同账号、存在、兼容、无重复实例。冲突返回具体槽位与原因，允许用户解锁；不自动改锁。
2. 枚举剩余公母的兼容组合。忽略缺失性别比例的概率加分，不使用竞品的未知比例=1降级。
3. 贪心填槽：每填一槽更新已覆盖蛋组/链和已用实例，再评分剩余组合。
4. 默认评分采用上述120/45/70/55/95/75/20权重作为**排序偏好**，不是概率；全部加分输出原因。破同分按 `(dexNo, maleGid, femaleGid)` 升序；目录序号缺失排最后。
5. 输出每槽母本对应的候选子代链/蛋目录，标注“静态候选”。没有验证过的产物规则时不写“必出”。缺口分为无种公、无种母、蛋组不兼容、已被其他槽使用、资料不足、锁定冲突。
6. 备用组合重新计算局部替换后的总覆盖，结果稳定、最多3条。更换只改本槽，保留其他锁定，显式选择“重新规划”才全局重算。

输出契约：`{uid,inputVersion,ruleVersion,status,slots:[{slotId,locked,maleGid,femaleGid,sharedGroups,score,reasons,candidateEggs,alternatives,warnings}],coverage,gaps,assumptions}`。状态 `ready/partial/stale/invalid`；概率字段没有证据时为null，并附reason，不能返回0冒充未知。

## 4. 页面与持久化

左侧目标/配额，中心窝卡，右侧产出与缺口。窝卡展示性别、性格、蛋组、实际dB、点击详情；锁定按钮有 aria-pressed。替换使用可搜索候选抽屉，确认前展示覆盖变化。加载、空库、无兼容、陈旧、锁定错误分别有可行动提示。

按uid保存配置与锁定实例ID，存独立计划仓库，带schemaVersion=1；业务数据来自快照。启动后重新校验，历史结果仅标记为陈旧。计划保存失败留预览并明确失败。

## 5. 真实家园接入门槛

当前家园页已解析0x014A两种快照布局、居民 `instanceId→pet gid` / `baseId→物种`、窝位、`layEggCouples`、场景蛋，并按解包版字段合并可识别的0x0413/0x0414增量。关系过期时家园页会按窝距/性别/蛋组显示范围候选；智能配窝规划尚未复用该规则。字段映射有合成回归，但尚未用本机真实游戏帧回放。仍缺：实际配对与场景窝位的真实帧验证、收蛋请求响应关联。

下一轮采集实验：同名双宠物上架→移位→移出→两公一母→单窝/多窝→收蛋，各动作保留操作时间与前后完整快照。只在实例字段和增量一致性测试通过后显示“当前实际配对”。距离推断不能覆盖已验证范围失败；新快照/移位使旧配对失效。

待验证假设：母本决定子代链、不同窝容量、学院窝特殊性格规则、多个父本等概率、声音±100遗传、体型/炫彩遗传。未经验证时只列候选与缺口，不显示确定概率、预计枚数或产蛋时间。

## 6. 验收测试

同uid唯一实例、跨账号隔离、同名不误合并、任何实例最多占一槽；锁定冲突和失踪；any蛋组兼容与未发现排除；缺性别概率不加分；评分可解释、同输入稳定；覆盖边际重算；备用替换不破其他锁；无候选返回partial；新版本使旧结果stale；所有未知概率null；持久化重启校验。真实配对测试需匿名真实帧fixture，合成位置只能验证计算，不能验证游戏规律。
