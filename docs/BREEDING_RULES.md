# 配种规则与双牌产线口径

状态：2026-10-16 联网核对与玩家经验，2026-10-17补充用户确认的智能配窝规划口径；不是游戏官方规则全集。读者：用户、功能维护者。维护范围：来源可靠性、已观察个体与配种预测的区别、产线判定与智能配窝假设。持续任务状态见 ROADMAP，页面边界分别见 COLLECTION_LINES_SPEC 和 BREEDING_PLANNER_SPEC。

## 智能配窝采用的宽容规划口径（2026-10-17）

用户确认智能配窝按“同蛋组双奖牌可以配出对应双奖牌”计算。该产品决策用于待实施的智能配窝，不修改本页保留的网络证据等级，也不自动改变筛选配对、双牌产线、家园及实际蛋仓的已有实现。

- 在同账号、异性、共享有效蛋组的前提下，双亲都具有目标体型牌和声音牌，即认定该父母组合支持对应双牌目标。父本允许来自其他物种，不要求双亲同性格、相同体型原值、满体重或±100dB。
- 对“大块头＋婉转声”目标，父母都为大婉即支持；大婉＋大粗只有共同大块头，大婉＋小婉只有共同婉转声。两只不同单牌不取并集合成双牌。
- 标记复用现有 `pet_marks`，佩戴及数值参考默认均可参与，保留来源；满身高不新造体型标记，历史获牌不替代当前标记。缺失标记保持未知。
- 双牌规则决定规划标签支持，不表示每颗蛋100%获得双牌，不新增奖牌遗传百分比。性格独立按普通/学院参考规则分析，性格不同不阻止基本配对。
- 使用最终布局内的全部兼容父本计算目标支持和性格参考，不能隐藏不匹配父本。默认按长期摆窝规划，母本有未取蛋时保留并提示取蛋后继续，不把即时占用当作永久不可用。
- 模拟画布暂用2×2占地、中心曼哈顿距离≤5的社区网格规则；当前家园代码使用另一套原始坐标边缘距离，尚未确认等价。两者不混算，真实校准和规则升级按规格执行。

完整行为、算法、来源边界及验收见 [智能配窝功能与实施规格](BREEDING_PLANNER_SPEC.md)。以下网络调研与当前页面描述保留各自日期和适用范围；有差异时，智能配窝的产品行为以该规格为准，游戏事实不能由规划假设反向证明。

### 无合格组合时的迭代参考（2026-10-17补充）

用户要求对缺合格父母本的目标展示相近亲本，并澄清示例为母本大婉、父本只有大块头但原始声音为95dB，不是95%刻度。父本声音接近目标，允许作为可能通过遗传浮动/迭代获得目标子代的参考；体重同理。此类组合独立标为“迭代候选”，不升级为合格双牌、不进入产线配齐分子。完整规则及样式见智能配窝规格§2.7、§4.5。

- 候选声音以原始dB显示和计算，不把95dB换成95%理解；现有家园百分比仅为辅助刻度，不改现有换算规则。工具96dB参考牌线不是遗传下限或已验证游戏获牌线。
- 项目当前 `trunc((父本dB+母本dB)/2)` 只是单点参考，没有完整遗传范围，不能据其均值不足或回交停滞排除真实遗传浮动/多代可达性，也不能用它反算推荐最低分贝。
- 有可靠遗传模型时，按该父母组合的子代声音/体型范围与目标获牌区间的交集判定参考可达。最低候选分贝/体重依赖配偶、浮动、取整/限幅、后代物种和获牌条件；证据不足时未知，不固定为92或95dB。
- 父本95dB但尚无婉转声时，可保留“声音接近，遗传范围待验证”的迭代候选；已知原始值而范围未知不等于原始资料缺失。母本只有佩戴牌时不补成100dB。
- 体重同样允许“未获体型牌但数值接近”的方向候选；保留其他目标牌，检查后代物种及必要身高条件，不直接平均跨物种千克数或把满身高当大块头。声音与体重范围分别可能达线，仍不证明同一子代必达双牌。
- 2026-10-17继续检索，找到Ya_星河[声体继承、奖牌区间与迭代视频](https://www.bilibili.com/video/BV19kj36cEcx/)，但页面正文/字幕未取得，不能由标题推断阈值或浮动幅度。旧玩家教程的均值浮动说法仍缺可复核分布，因此真实最低分贝保持未知。

实现上把“已有奖牌匹配”“遗传范围支持/仅方向接近”“原始资料不足”分开：迭代卡使用琥珀虚线和明确文字，父本95dB、尚缺婉转声及范围证据分别展示；实际子代入库后再按真实个体重评。此设计不降低原合格判定的标记线，不改写已有背包和家园数据。

已确认策略（1B/2B/3B/4A/5A/6A/7B）：范围未知的迭代方向候选允许规划，但自动推荐仅缺一类奖牌，必须由用户主动选择后带入；在优先级与硬约束内追求更多目标覆盖及有效母本，同级集中库存优势目标。为增加覆盖可减少未锁定合格母本，但合格/迭代分别计数、保留原方案，不能把数量偏好当成真实产蛋率或将近似改成合格。

## 网络调研补充：小窝、产蛋与后代规则（2026-10-16）

本节记录本轮搜索到的《洛克王国：世界》配种资料。资料主要来自玩家攻略、玩家实测和社区 WIKI；它们适合建立候选筛选与实验记录，不足以单独证明游戏内部概率公式。实现时按“确定性前提 → 可解释估算 → 未知”分层，不把经验概率显示成保证。

### 小窝摆放与生蛋前提

- 公开的小窝排布计算器把每个小窝视为 `2×2` 平面区域，小窝之间不能重叠。
- 该工具使用小窝中心的曼哈顿距离判断范围：`|x1-x2| + |y1-y2| ≤ 5` 时，异性精灵有机会配种。这里的“有机会”不是必定产蛋；距离公式目前属于可复核的社区工具规则，仍需用真实版本操作确认。
- 配种基础条件是异性和同蛋组；同蛋组不要求物种相同。攻略称后代物种由母本决定，进化分支通常不改变配种关系。
- 母本产生蛋后，需要先取走蛋，才能继续生蛋。规划器必须把“已产蛋未取走”作为当前母本不可继续使用的状态，而不是把她当作永久不兼容。
- 生蛋时间的公开攻略范围为 `0.5～20` 小时，未找到可靠的时间分布或影响因素公式；项目只应记录实测时长，不应根据该范围推算确定完成时间。
- 生蛋和孵蛋是两套计时：攻略称同时最多孵化 3 个蛋，孵化进度按角色移动距离推进，取回孵化中的蛋会重置进度。这些内容同样属于攻略口径，需按版本复核。

来源：[小窝排布计算器](https://calecgos.github.io/roco_nest_placement/)、[精灵蛋系统介绍与生蛋攻略](https://www.gamersky.com/handbook/202604/2116160.shtml)。

| --- | --- | --- |
| 后代物种 | 普通配种按母本物种确定 | 多篇攻略一致，但仍属于社区资料 |

| 个体资质 | 有“父母各取2/3条后再随机补齐”的说法 | 与“父一条、母一条、另一条随机”的实测说法冲突，不能硬编码 |
| 天分 | 父母天分越好，后代出现较高天分的倾向越强 | 缺少可复核的映射和概率，特殊蛋需要单独处理 |

性格的 `30/30/40` 来自[玩家遗传机制整理](https://www.233leyuan.com/post-detail/2053039458908291072)，并在[700 多蛋玩家总结](https://www.taptap.cn/moment/803915124980056655)中以“网上通用说法”出现。该比例可以作为页面上的“社区估算”，不能作为后代确定性预测。

### 特性、特长、体型和声音

“特性”和“特长”需要分开记录：

- **特性**通常是物种图鉴中的战斗能力，例如小黑猫图鉴列出的“预警”。目前没有找到亲本将这种物种特性直接传给后代的证据，项目应按后代物种读取。
- **特长**是“爱分享、亲密、灵巧、疾行”等个体标签。图鉴会列出物种的特长概率，并注明“一般般的天分无法获得特长”；玩家总结则认为特长不按父母直接继承，更接近后代随机结果。
- **体型**方面，玩家经验认为双亲具有相同极端体型时概率更高，一方具有时概率较低；身高接近边界不能直接等价为“大块头”或“小不点”。
- **声音**方面，搜索到的资料提到可能存在亲本影响，但没有取得可复核的完整继承公式，暂不计算固定概率。

来源：[小黑猫图鉴](https://wiki.biligame.com/nrc/%E5%B0%8F%E9%BB%91%E7%8C%AB)、[精灵蛋图鉴](https://wiki.biligame.com/nrc/%E7%B2%BE%E7%81%B5%E8%9B%8B%E4%B8%80%E8%A7%88)、[玩家孵蛋总结](https://www.taptap.cn/moment/803915124980056655)。图鉴是社区维护资料，特长概率不等于已经确认的亲本遗传公式。

### 特殊蛋与普通配种的边界

剧情蛋、活动蛋、完美蛋、异色蛋和炫彩蛋可能自带固定的外观、天分、性格、特长或定制资质。社区图鉴对多种特殊蛋明确标注“了不起”天分和定制资质。它们不能直接反推普通小窝的遗传机制，也不应和普通配种结果混入同一套概率。

### 项目实现分层

| 层级 | 首版处理 |
| --- | --- |
| 确定性前提 | 性别、同蛋组、母本物种、同账号、窝位不重叠、距离候选、母本产蛋占用状态 |
| 社区估算 | 性格30/30/40、父母天分对后代天分的倾向、异色/炫彩概率提高 |
| 仅作参考 | 个体资质具体继承条数、第二血脉、体型和声音继承概率 |

### 双牌培育流程示例

以“固执＋大块头＋婉转声”的鸭吉吉为例，楼主建议按奖牌→性格→个体值推进：

1. 准备目标性格的大块头婉转声种公，以及能够与其配种、具有婉转声的母鸭；母本起步可没有大块头。种公可以是共享蛋组的其他种族。
2. 配种后筛选更重的母鸭替换母本，继续与种公配种，逐步取得大块头婉转声母本；筛选体重时可以同时考虑目标性格。
3. 保留双牌并筛选目标性格子代，最终形成符合目标的公母组合。
4. 最后使用钥匙完善个体值。楼主建议刚达到大块头的母本再加重迭代一至两次，以稳定产出；没有提供量化成功率。

两只不同单牌不能直接当作稳定双牌组合。例如粗嗓门单牌父本＋大块头单牌母本，教程建议改用大块头粗嗓门父本＋粗嗓门母本，先保留共同声音，再迭代体型。这不证明原组合绝无偶然出双牌的可能。

### 满身高与实际奖牌必须分开

评论中的火神案例给出身高范围1.52～2.18，子代逐代达到1.61、1.85、2.06、2.18；记录者明确表示第四代已到身高上限，但因体重不够仍非大块头，后续才得到双牌。另有评论称“身高够的单声音也能当双牌”，应理解为潜在培育亲本经验，不能据此修改其自身奖牌状态。

因此，“身高100%、体重89%、仅婉转声的熔岩布丁”必须保留实际单牌状态，不计入大婉配齐数。评论中的五六代出双牌、声音取平均值浮动、炫彩颜色偏向父本等说法缺乏完整样本；楼主也对颜色继承表示难以验证，不采用为确定算法。

## 当前判定与页面

- 本页是“双标亲本收集”，不是已获得奖牌全集、实际配窝状态或子代概率计算器。所有百分比按该物种固定参考范围计算，与当前筛选结果最大值无关。
- 与背包共用 `pet_marks`：对应佩戴奖牌优先；否则体重处于有效范围的末2%／首2%作大／小参考，原始声音96～100／−100～−96作婉／粗参考。阈值是现有工具口径，不标成官方已核验获牌条件。正负100和满体重附加条件仍用原始整数精确比较。
