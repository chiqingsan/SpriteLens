## 2. 总体结论

最适合 SpriteLens 的新增方向是：

> **附近精灵列表 → 距离/方向 → 目标条件 → PVE 告警 → 雷达/悬浮监控**

其中“附近精灵列表 / 雷达 / 距离”在 `小洛克精灵工具箱` 报告中是明确描述的完整功能；RocoWildScanner 报告则提供了实体字段、玩家坐标、相对距离/方向和稀有目标告警的实现线索。

适配时应保持 SpriteLens 的现有边界：

- 继续使用被动 Npcap 捕获，不注入、不改包、不自动化操作。
- 协议解析沿用 `capture → protocol → domain/services → view_models → web` 的单向分层。
- 不把竞品的云端交易、远程同步、联系方式和原始密钥存储带入本地优先产品。
- 未知字段、部分快照、丢包和协议版本差异保持可见，不使用静默默认值掩盖。

## 3. 与当前 SpriteLens 的重合范围

以下能力已经存在或已经有对应页面，不应按竞品报告重新规划：

- 精灵背包、筛选、详情和奖牌标记
- 蛋仓、蛋蛋图鉴和孵化相关能力
- 炫彩色卡
- 家园、种公库、产线收集和智能配窝
- 本地图鉴/Wiki
- 被动采集、自动启动、录制、回放和本地事件日志
- 账号身份识别、账号切换和头像缓存

蛋神助手报告中的背包、蛋蛋、色卡、产线、图鉴和配种页面，主要作为字段组织、筛选器和交互细节参考，不作为重复实现目标。

## 5. “附近精灵”功能的证据拆分

### 5.1 明确观察

小洛克精灵工具箱报告明确写出：

- 存在“附近精灵”页签。
- 页面包含列表、雷达和地图视图。
- 支持八方向显示。
- 距离通过二维坐标差计算，报告给出 `hypot(dx, dy) / 100` 米的形式。
- 工具链使用被动 Npcap 捕获、TCP 重组、密钥提取、AES 解密、protobuf 解码和本地 API。

RocoWildScanner 报告明确写出：

- 世界实体中存在配置 ID、唯一 ID、等级、身高、体重、音量等字段。
- 玩家坐标通过独立消息解析。
- 可以计算相对方向和距离。
- 普通实体进入 JSONL，命中条件的实体进入告警和地图标记。

### 5.2 当前只能作为推断的部分

- 报告中的距离单位是否适用于当前 SpriteLens 版本，需要用当前录制验证。
- 场景实体的增量删除、跨场景生命周期和实体唯一 ID 复用规则尚未完全确定。
- 雷达坐标是否直接等价于世界坐标，还是经过场景/楼层变换，尚未确定。
- 目标告警字段与当前 `pet_marks` 的语义可以复用一部分，但附近实体不能直接当成背包精灵处理。

### 5.3 实现前必须验证的录制场景

1. 登录前后是否能稳定取得解密所需密钥。
2. 进入场景时实体批量出现，离开场景时是否有明确删除或替换消息。
3. 玩家移动后距离和方向是否按预期更新。
4. 进入战斗后附近实体如何变化，战斗结束后是否恢复。
5. 切换账号或重新登录时旧实体是否被清空。
6. 丢包、未知 opcode、部分实体字段缺失时，列表如何标记不完整状态。
7. 回放路径与实时路径是否产生一致的附近快照。

## 6. 推荐实施顺序

### 第一切片：C01 采集向导与诊断

验收：新用户能知道 Npcap、网卡、端口和采集状态是否正常；失败时有明确下一步；不影响现有录制和回放。

### 第二切片：C02 + C03 附近精灵列表

验收：在匿名录制和回放中能展示实体、距离、方向、更新时间和不完整状态；场景切换、账号切换和停止采集不会残留旧数据。

### 第三切片：C04 + C05 目标监控

验收：能按异色、体型、音量等条件产生结构化目标事件；重复消息不会持续刷屏；历史记录能追溯实体字段和发现时间。

### 第四切片：C06 + C07 雷达与悬浮监控

验收：雷达和悬浮窗口只消费结构化附近/告警状态，不自行解析协议；关闭、切号、停止采集和异常退出不会留下后台任务或窗口。

### 第五切片：C08 安全导出

验收：普通导出可以用于问题反馈和离线分析，但不会包含 session key、token、pcap 或未脱敏账号数据；导出失败不覆盖已有文件。

## 7. 对实现者的约束

- 新的场景解析应放在协议/领域边界，不把 SceneTracker 逻辑塞进 `web/static/app.js`。
- 附近实体与背包宠物是两个不同业务域；只有明确的配置映射和来源字段才允许复用展示组件。
- 实时推送应沿用现有 `/ws` 快照语义，列表页按需请求，不为每个实体创建独立连接。
- 长列表需要限制 DOM 数量；目标告警和事件历史需要限制内存增长。
- 保存路径必须经过现有用户数据目录和原子写入约定；抓包线程不直接执行慢 IO。
- 普通导出和诊断包必须显式列出包含的域、账号 uid、数据版本和未知字段。
- 任何“已支持”的协议结论都必须附带录制、回放或运行时验证证据；静态报告只能作为候选实现依据。

## 8. 暂不纳入当前核心范围的功能

- 云端交易市场、用户联系方式、远程交易状态和云同步。
- 完整地图瓦片、来源不明的第三方地图资源和大规模地图标记。
- 直接复制竞品的全量 `all` payload 或加密导出信封。
- PVP 全量战斗预测和自动化操作。
- 3D 服装/精灵模型实验室。

这些方向不是永久否决，而是需要独立的隐私、资源来源、协议完整性或运行时验证评估，不应阻塞附近精灵第一版。
