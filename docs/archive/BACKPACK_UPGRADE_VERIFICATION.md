## 登录后昵称和 UID 不更新

前端 `bindCaptureActions()` 仍给已删除的 `btn-start` / `btn-stop` 绑定事件，空节点抛异常后，启动流程未执行到 `connectPush()`。初次 bootstrap 可以渲染，所以表现为登录后仍显示“等待识别角色 / UID —”。

已删除残留绑定，并将启动成功标记移到绑定和实时连接初始化之后。新增静态节点绑定回归，避免删除控件后遗留同类错误。

另将 0x0102 的消息映射补为已有的 `ZoneLoginRsp`，身份解析支持经实测的 `player_info → brief_info → uin/name/role_level`。保留进场景 `self_info → avatar → base` 路径，禁止从其他玩家或 NPC 提取身份。新增临时服务测试：先建立 WebSocket，再注入登录响应，确认角色推送及宠物位置载荷。

**使用时需要关闭并重新打开 SpriteLens，再登录游戏。** 旧进程不会自动加载新的前端、协议映射和数据库迁移。离线历史精灵和位置不会冒充本次已识别的角色。
