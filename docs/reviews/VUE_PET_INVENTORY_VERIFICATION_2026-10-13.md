# F03 第二刀：请求、三视图与箱位迁 Vue

状态：2026-10-13 本机与浏览器验收记录。读者：实现者、维护者、架构复核者。
维护边界：本切片证据；持续状态在 ROADMAP，不表示详情/扩展筛选或桌面发布验收完成。

## 目标与状态归属

保留既有工作区修改，在第一刀基础筛选之上迁移请求与加载错误、列表快照、三视图、分页、箱/队和选择。
usePets 是这些页面状态的唯一所有者；PetInventory 与子组件独占列表、导航、分页、视图按钮和计数。
app.js 删除对应数据副本和列表生成/绑定；仅保留导航、旧 WS、偏好、详情与扩展筛选桥接。
Python 继续拥有业务规则和真实仓库；没有新增依赖、WS、全局状态管理或网络客户端。

原生 account-requests.js 的 petContext 只提供已有 uid/版本/代次的读副本，账号仍只有旧 state 入口更新。
Vue 请求用既有 API 客户端和本页序号/AbortController；没有再维护一套账号或版本递增。
基础筛选请求失效命令转到 usePets；原生扩展筛选查询合入同一次请求。
详情通过 find/payload/selected 和选择/定位命令消费 Vue 所有的数据，不反向写私有状态或列表节点。

## 行为与失败分支

- 输入立即失效旧请求；离页取消、返回按当前条件同步；切号清快照、选择、箱号与队伍。
  同页乱序、A→B→A、错 uid、过期版本均不能提交。取消无效也依靠票据/账号核对拒绝。
- bootstrap 在显示主界面前解析 DTO 并核对账号/版本；坏数据走原启动重试提示。
  当前请求失败保留可读错误与直接重试入口；旧/已取消请求失败不提示当前用户。
- DTO 校验本页消费的行/选项字段、30 格箱和 6 格队、gid 安全范围、槽状态与 matched 个体对应关系。
  unknown 的 gid 为 null，明确 empty 的 gid 为 0；不会把未采集/资料未到/筛掉视为普通空位。
- 保留箱号批次/跳转/命中导航、三队、历史提示、固定箱位与 60 只卡片分页；表格仅在所选视图构建。
- 列表选择与详情键盘/焦点、定位到箱/队及返回选择通过桥协作；盒号切换保留选择，视图/浏览页切换清选择。
- Vue 模板承接头像/立绘、稀有标记、色卡/粒子、奖牌和展示格式；不注入旧脚本 HTML。
  名称安全插值，图片失败保留文字/头像首字；复用主题、资源路径、样式与控件 ID。

## 验证

- 新增 5 项 Vitest：受控乱序/输入失效/离页、账号代次/归属/版本与重试、分页收敛与切号清理、
  错误槽/unsafe ID/匹配缺失、三视图/安全文本/焦点/非活动表格不构建。
- 新增 3 项 Playwright：130 只精灵分页与完整表格、11 箱跳转、三队 18 槽、
  历史/四种槽语义、箭头跨槽与 Enter/Escape 详情、错误重试/坏槽拒绝、详情定位后焦点、
  切号后取消无效的 A 响应不覆盖 B 列表；三主题表格截图生成，喵喵截图检查布局与溢出。
- 全量门禁：417 Python（5 既有跳过）、15 Vitest、类型/ESLint、11 JS、HTML 引用、
  16 静态清单及 Vue 产物指纹/哈希通过；14 Playwright 通过。
- Vite 暂存构建/发布、临时数据目录源码 smoke 与差异检查通过。
  生产 JS 138.79 kB / gzip 51.08 kB（Vite 输出）；未测桌面冷启动。
- 使用合成数据和临时目录；没有真实账号、录制、密钥或素材压缩改动。
