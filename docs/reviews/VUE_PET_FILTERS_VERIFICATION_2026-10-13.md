# F03 第一刀：宠物基础筛选迁 Vue

状态：2026-10-13 本机与浏览器验收记录。读者：实现者、维护者、架构复核者。
维护边界：本轮切片证据；持续状态在 ROADMAP，不表示整个宠物页或桌面发布验收完成。

## 目标与范围

保留已有工作区改动。在 F01/F02 契约上迁移搜索、排序/降序、等级、性别、性格、系别和天赋。
后端筛选规则、账号观察与请求票据、三视图/箱位、详情、扩展筛选和快捷条件持久化沿用原实现。

Vue 的 usePetFilters 独占基础状态，PetBasicFilters 独占基础控件、搜索/排序与天赋 Teleport 子树。
app.js 删除基础筛选副本、选项缓存、生成与绑定逻辑；ui.js/backpack-controls.js 不再写这些控件。
筛选标签与满级快捷条件通过命令桥操作；矩阵跳转通过 search 命令；查询只传当前条件给既有请求管线。
已保存快捷条件含扩展字段时，基础模型仅恢复自身字段，避免把蛋组/体型复制为第二份权威状态。
原生扩展筛选继续自持状态；未增加 Pinia store、API 客户端、WS 或依赖。

## 实现与失败分支

- 搜索 220ms、等级 180ms 防抖；输入立即取消/失效旧 pets 票据，不能等防抖结束才废弃旧结果。
  F02 继续校验代次/序号/uid/域版本；即使传输层取消失效也不会提交旧结果。
- 离页暂停输入定时器、返回保留基础条件；切号清账号派生选项与选择，关闭卸载清 timer/Teleport。
- options 只校验本切片消费的 natures/types/sorts/talent_max；错误由原加载失败提示暴露，旧选项不被坏数据替换。
- 游戏箱位隐藏排序，卡片/表格保留；等级上下限联动、性格折叠/选中可见、按钮焦点与 aria 状态由 Vue 维护。
- 复用旧 CSS/主题/控件 ID；display:contents 保持原筛选栏网格间距，避免挂载容器改变布局。
- 源构建稳定入口同时导出 mount 和 mountPetFilters；仍暂存校验后发布专用目录。
  bootstrap 挂载失败走原启动重试/失败提示，不显示成功界面。

## 验证

- 新增 5 项 Vitest：防抖/失效、离页/切号/恢复清 timer、上下限与状态归属、坏 DTO、
  安全插值、选项更新保留节点与焦点、更多性格、固定箱位、卸载与重复挂载。
- 新增 4 项 Playwright：真实 HTTP 基础筛选/排序/空态/重置、三视图兼容、
  筛选标签移除、固定/恢复快捷条件、键盘焦点与三主题；离页不发延迟请求；坏选项提示与恢复；
  传输层取消无效时在新输入的防抖等待期间释放旧响应，仍保持更新状态，随后只提交新条件；启动坏选项时保留启动提示，重试成功不重复挂载。
- 全量工程门禁：417 Python（5 既有跳过）、10 Vitest、类型/ESLint、11 JS、HTML 引用、
  16 静态清单及 Vue 产物指纹/哈希通过。

- Vite 构建发布与临时数据目录源码 smoke 通过。仅合成数据，不保存真实账号/录制/密钥。
- 生产 JS 111.48 kB / gzip 42.62 kB（Vite 输出）；未做桌面冷启动或 exe/WebView2 实机验收。
