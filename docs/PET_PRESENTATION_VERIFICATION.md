# 精灵背包展示改造与核验（2026-10-12）

最新紧凑三栏布局、纯百分比展示和817个头像变体的透明留白归一已实施，见 `PET_CARD_LAYOUT_PLAN.md`。原头像和全身图保留，资源覆盖物种数不因派生图片增加。下文布局记录为此前版本；资源、色卡与标记规则继续适用。

## 交付

> 布局现状见 `docs/UI_GUIDE.md:197` 的「定稿布局（2026-10-13）」；以下为当时版本的布局记录。

- 首捕统计、过滤、快捷条件、列表列和详情标记全部移除；协议原始字段/数据库列保留兼容。旧固定条件移除该字段，其余条件和名称保留。
- 背包默认使用头像；外观设置可切全身图，保存到 `ui.preferences.pet_image`。主题、显示字段和后续偏好保存均保留图片模式；非法配置回落头像，非法接口值返回错误。
- 卡片顶部性别/等级/性格；中段左侧为 72px 头像区域，头像下方放稀有标记与独立色卡，右侧放文字标记/蛋组；姓名独立一行，底部三列仅标 m/kg/db。各区域采用固定行高，头像与标记不叠放。范围位置可独立显示。
- 删除卡片和空格左上槽位序号、右上选中角标；真实行列仍保留在无障碍名称和详情中。选中仅使用描边。
- 紧凑标记仅显示大/小、粗/婉两组文字，组内互斥，最多两项；其它佩戴奖牌仅在详情显示名称。
- 男女底色分别蓝/粉，未知中性。选中用主题描边，保持性别底色。属性卡片同样使用性别底色；详情与表格复用图片模式。
- 删除图片后的渐变色底，不做悬浮放大或炫彩着色模拟。
- 色卡图形在背包、详情及色卡矩阵共用；普通精灵即使携带 glass 字段也不算炫彩持有者。

## 核验过的规则

只读核对蛋神 v1.1.6 的 `webui/app.js`（rarityDescriptor/colorArt）及 `color_cards.pyc` 的静态反汇编；没有运行竞品程序。

- mutation_type 的 bit 0 为异色、bit 3 为炫彩，二者可以同时成立。
- 普通卡号取 `glass_value & 0xFFFFF`，粒子取 `glass_value >> 20`，已知值 1/2/3/4 对应四角星/爱心/方块/镂空五角星。
- glass_type=2 的低位 1..4 为 s1..s4，1000 为黑白卡。特殊卡使用对应独立图片，不套普通卡波浪模板。
- 普通色卡上方为混色、下方为底色，波浪分界；粒子叠加独立透明图。波浪形状属于展示布局，不是抽卡概率。
- 觅觅蝠实际缓存样本 gid 26925：glass_value=1048613，即卡 37＋四角星，混色 #f1d397、底色 #3c32cf。此前摘要的 1048611 不准确，已按本地数据校正。
- 未知卡号不造色；未知粒子不默认猜四角星。
- 只读反汇编 `pet_medals.pyc` 的 `enrich_pet_medals`：体重在有效物种范围的位置 ≤2% 对应小、≥98% 对应大；声音 −100..−96 对应粗、96..100 对应婉。体重采用整数交叉乘判断，避免百分比舍入导致边界误判。
- 对应佩戴奖牌（1001/1002/1025/1026）优先；否则显示参考标记，提示明确区分“当前佩戴”和“体型/声音参考标记”。参考标记不表示已获得游戏奖牌，未知/退化体重范围不生成大小标记。

## 图片来源与覆盖

可重跑 `tools/sync_pet_media.py <竞品解包目录>`；稳定 ID 对照，记录地址和源文件 SHA-256。只导入当前精灵展示所需资源，运行时无外网依赖。

- 官方 manifest 版本 2026-09-19，头像 `portrait/icon.png` 和全身 `artwork/image.png` 为不同资源，普通/异色分开映射。镜像缺失时访问 manifest 明确记录的官方 CDN 地址，并校验哈希。
- 本轮查明上一版混图原因：社区目录的部分 iconUrl 虽然名为 icon.png，实际内容是全身立绘。导入器已取消该来源，用目录确认的稳定 ID 查询 manifest 已验证的官方头像路径，成功下载/解码后才入映射，来源单独记录 derivedFrom。旧同名错误资源首次强制更新。
- 1060 条历史/当前物种中有 620 种普通头像、197 种异色头像、478 种普通全身图。当前账号实际持有物种普通头像覆盖 100%。
- 440 条无普通头像的历史/特殊物种保留首字占位；官方部分异色地址 404 时回退同种普通头像。头像模式不回退全身图；全身图缺失使用已有本地小图，最后回退首字。
- 异色标记、四种粒子模板、黑白/赛季色卡从解包游戏资源目录引入。游戏资源没有发现单独开源授权声明，来源信息如实记入报告。
- 机器可读覆盖与失败明细：`data/static/pet_media_report.json`；运行期映射：`data/static/pet_media.json`。
