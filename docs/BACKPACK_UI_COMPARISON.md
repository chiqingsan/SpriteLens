## 4. 当前 UI 仍欠缺的点

### 优先改：能明显降低操作成本

1. **筛选栏过长、主次不清。** 性格/系别/蛋组默认全部展开，重要的数值范围与显示选项被挤到下面。保留常用条件，其他按组折叠，标题显示已选摘要；显示选项移至背包工具条。
2. **定位能力不足。** 精灵实例编号对用户回游戏找精灵帮助有限。优先补可靠的真实箱位，详情提供文字定位与小格图。
3. **卡片缺业务识别层。** 目前性别/性格/等级/首捕/体型都在争抢注意力，特性和稀有形态又缺失。固定身份区、图片区、业务徽标区、数值区；提供紧凑/标准密度。
4. **“范围位置”可见性不足。** 当前主要出现在详情文字内。可增加卡片选项、端点与位置条，清楚区分实际值、物种范围和蛋基础范围，越界和未知各自有状态。
5. **数据可信度反馈不足。** 有数据不等于数据完整、最新。显示当前账号、快照更新时间、待补全数量；0dB 与声音缺失目前模型无法区分，应先修正数据表达。

### 第二层：视觉一致性与长时间使用

6. **字号和对比度层次偏弱。** 次级标签、小数值说明和灰字密度较高。控制辅助文字数量，关键数值至少正文大小，选中不只依赖浅底色。
7. **数值格式不统一。** 卡片/详情小数位与单位间距不同；声音正负号、暂无数据文案占用宽度不一致。统一格式并为表格使用等宽数字。
8. **详情缺少“查完下一步”的入口。** 详情可加入同蛋组、完整进化链、技能说明的相关入口；顶部保留筛选摘要，继续浏览无需来回查找。
9. **独立对比任务还不够方便。** 当前表格是所有匹配结果，尚不能把 2–4 只精灵暂存到对比栏，针对六维、体型、声音比较。
10. **滚动内容缺少可发现提示。** 隐藏滚动条后，右栏和卡片列表底部可增加轻微渐隐或剩余内容提示，让用户知道下面还有内容。
11. **侧栏条目较多。** 多组工具与资料并排，长期可考虑分组收起或常用固定，保留当前明确分组；不再添加导航副标签。
12. **设置信息架构仍分散。** 外观放在采集页适合当前阶段，后续统一设置中心再将外观、视图、采集、存储分组。
