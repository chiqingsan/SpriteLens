# UI 规范（现有 web/static 与 Vue 组件）

适用范围：当前 `spritelens/web/static/` 与后续 `frontend/` Vue 工程中的全部界面工作。加新页面、改组件、调样式
之前先读这份；与 `DEVELOPMENT_GUIDE.md` 的前端约定配合使用（那边管架构与
安全转义，这边管视觉与组件）。

## 1. 参照系与设计立场

- **蛋神助手**（布局对标对象）：它的 `:root` 与我们同源，视觉密度为
  数据面板风格——保留紧凑布局，正文 13~14px、辅助字 12px、密集角标最低 11px。
  最重要的观察：**它几乎不用阴影**（大量 `box-shadow: none`），质感来自
  1px 描边 + surface 分层底色。我们也照此执行：能靠描边和底色分层解决
  的，不加阴影。
- **Open Props**（分级节奏参照）：间距 4px 步进、少档圆角的 scale 思路。
- **自然绿参考主题**：暖白 `#F6F6ED` 工作面、浅绿分组侧栏，主按钮 `#5F7D48` 配白字；
  浅绿 `#E1EC8F` 仅搭配深字。精灵立绘、色卡和系别配色保持业务含义。
- **shadcn/ui**（命名思想参照）：语义化变量命名（什么用途，而不是什么颜色）。
  我们的 `--surface-2`、`--ink-soft`、`--amber-ink` 都是这个思路。
- 前端已确认采用 Vue 3 + TypeScript + Vite；视觉 tokens、紧凑布局和离线资源约束保留。
  初期复用 CSS 变量与组件语义，不引入第二套主题体系；组件库按实际需要评估，迁移方法见 [VUE3_MIGRATION](VUE3_MIGRATION.md)。

## 2. Token 速查（颜色预设在 themes.css，布局在 app.css，禁止绕过）

侧栏切页直接显示目标页面，不做整页透明度/位移入场动画。返回页面保留内容与滚动位置，按账号、数据版本和筛选条件决定是否刷新；按钮等局部交互仍保留过渡。蛋蛋图鉴按滚动分批显示卡片，返回时复用已加载内容。

**选值规则：先查这张表，表里没有的语义先加 token 再用；禁止在规则里写
hex/rgba 字面值。** 1px 属"贴紧"语义、`999px` 胶囊、`50%` 正圆，可直接
写字面值。

| 组 | Token | 用途 |
|---|---|---|
| 间距 | `--space-0..7` = 2/4/6/8/10/12/16/20px | margin/padding/gap 全部走它；禁止 3/5/7/9 等奇数散值 |
| 字号 | `--fs-3xs..2xl` = 11/12/12/13/14/15/20/26px | 密集角标 → 辅助标签 → 次要信息 → 正文 → 强调正文(基准) → 面板标题 → 页面标题 → 大数字 |
| 圆角 | `--radius-sm/md/lg` = 6/8/12px | 小徽章/chip/输入框 → 卡片/按钮/头像（默认） → 面板/弹层 |
| 阴影 | `--shadow` / `--shadow-hover` / `--shadow-pop` / `--shadow-inset` | 面板静置 → 卡片悬停（hb-card/pet-card/nav active 共用） → toast/浮层 → 头像内阴影 |
| 表面 | `--surface-1..4` | 工具条底 → 常用次级底（行悬停/chip/账号行） → 更深一档（轨道/占位头像/按钮静置底） → 按压最深档 |
| 线 | `--line` / `--line-soft` | 常规边框；表格内弱分隔用 soft |
| 文字 | `--ink` / `--ink-soft` / `--muted` / `--muted-2` | 标题 → 深青正文 → 次要说明 → 占位字/徽章淡字 |
| 品牌 | `--teal` 四阶 + `--teal-bright` + `--focus-ring` + `--accent/--on-accent` | 保留变量名，映射喵喵绿/火花红/水蓝蓝蓝；浅选中背景必须搭配深字 |
| 琥珀 | `--amber` 六件套 | 处理中状态与提示条专用（`--on-amber` 是渐变底上的深字） |
| 危险 | `--danger` 四件套 + `--positive/--negative/--ok` | danger只留破坏性操作；火花主色使用独立品牌token，数值升降用positive/negative |
| 性别 | `--male/--female` + `--male-strong/--female-strong` + `--male-ink/--female-ink` | 环形标记与性别符号；精灵卡片按性别使用浅蓝/浅粉底色 |
| 侧栏 | `--sidebar-bg/text/muted/line/hover` + `--selection-mark` | 浅绿底、文字、分隔、悬停与选中标记；`--deep-*` 保留给深色业务表面 |
| 解码树 | `--code-*` 五色 | colorizeDecoded 白名单着色，与 tok-* 类名对应 |
| 图表 | `--chart-h/w/v` | 体型条三色，与 `.body-bar i` 类名对应 |

业务色（系别/天赋阶/glass 渐变）不属于 CSS token：由 `domain/display.py`
经 payloads 下发，前端不复制色表（见 DEVELOPMENT_GUIDE）。

### 三主题与偏好

`themes.css`默认喵喵，`data-theme=huohua/shuilanlan`覆盖色值；共用浅色布局。
`appearance.js`只更新根样式/显示类，不重建数据；设置页三枚主题名称按钮立即应用，不使用精灵图片。宽屏为说明与按钮的紧凑设置行，窄屏上下排列。
`ui.preferences`仅保存theme、pet_view、fields，经鉴权`GET/POST /api/ui/preferences`读写，bootstrap恢复。
非法配置回默认，非法提交400；原子写入失败500，UI保留预览并明确提示失败。
蛋组/数值/业务筛选不跨启动保存；显示选项不影响筛选计数。

应用品牌标识使用好奇版绿色头像（`resources/icon_source.png`）：微歪头、大椭圆眼睛高光、眼底绿色亮面与短 W 形嘴；以 16/24/32px 的辨识度检查眼神。
经 `tools/make_icon.py` 派生窗口/任务栏 ICO 和 `favicon.png`；浏览器标签页与侧栏品牌标识复用后者。

优先Tabler官方outline，缺语义再Lucide。`icons/*.svg`及sprite为24×24、2px圆角描边、currentColor。
`icons/sources.json`记录版本/URL/许可/搜索标签，MIT全文在`icons/LICENSE.txt`。
`tools/sync_ui_icons.py`只在开发导入时联网；`icons.js`装饰导航/控制/空状态，图片和性别符号保持原样。
六维性格方向使用本地Tabler `arrow-up` / `arrow-down` 图标，笔画为2.5px；属性文字与方向图标放在同一SVG组并垂直居中。属性数值为0的天赋加成省略，非零加成紧随当前值显示。
滚动条全局隐藏外观，overflow不变；导航也适用，不重新设置thin。

### 精灵蛋仓

蛋仓沿用三主题，桌面按约 2:1 分为列表与详情。工具栏将缓存状态、点击切换升/倒序的按钮和搜索放在同一行；两种顺序用箭头、边框和底色区分，类型筛选铺满下一行。
列表卡片使用统一竖向比例，依次展示蛋图与名称、单行标签、尺寸/重量和获得时间；有无标签都保持相同尺寸和数据行位置。普通窝在左上角显示灰色胶囊，学院绿窝显示绿色胶囊，无窝标签时不显示；收藏按钮位于右上角，真实在孵状态和堆叠数量保留角标。
卡片最小高度为240px，顶部角标行至少保留24px，无角标也不塌陷；蛋图与名称整体上移20px，标签行上移8px以缩短上沿留白并保留组内间隔；异色蛋名称尾部显示1em异色标识，与名称间隔6px；卡片内容行间距为4px，名称下移4px、数据区上移4px以收紧名称/标签/数据区之间的留白，底部尺寸/重量与日期行间隔6px。
性格使用浅绿标签，声音使用浅紫标签，体型奖牌使用浅金标签；四枚标签时收紧间距，保持单行。无其他标签时显示“一颗充满活力的精灵蛋，正等待新的冒险。”，仅有窝标签时也显示该文案。列表按可用宽度使用一至五列，保持卡片文字可读；选中使用主题描边与浅底，不抬升卡片。
列表自身显示主题滚动条；卡片按批次渐进挂载，滚近底部再追加，筛选和排序变化时从顶部开始新批次。蛋图使用浏览器原生图片懒加载并异步解码。
详情包含蛋图/名称/蛋组、标签状态与编辑、数据对比和孵化记录；未知范围显示占位，超界仍保留实际值并明确标记。性格可在蛋仓手动选择；蛋窝默认为自动，家园拾蛋默认为普通窝，允许改为学院绿窝。
重量极值在目录范围端点的误差不超过整个范围宽度0.1%时自动显示；大块头/小不点沿用精灵标记的2%范围规则。声音标签和声音奖牌取自手动绑定精灵的分贝值；精灵详情允许录入−100到100的整数分贝。
尺寸与重量复用本地 Tabler `ruler-2`、`weight`，与时钟/排序图标保持同一描边风格。性格、蛋窝、精灵绑定和手动分贝按账号持久化。

### 筛选配对（F04-U4，2026-10-16）

沿用暖白卡片、性别描边、性格chip、本地奖牌图和UiIcon。主区父本／母本双栏，各自滚动和分页，每侧最多24只；翻页控件紧邻列头的选择提示，列表占满列头以下空间。顶部搜索、性格一致与刷新保持紧凑。右侧固定360px（较窄桌面320px），持续显示筛选设置，列表宽度保持稳定。筛选多项奖牌同时满足，蛋组／性格同组内任选。声音、身高和体重复用DualRangeSlider双头滑条，声音−100～100dB、体型0～100%；每行左侧名称、右侧当前范围摘要，底部两端显示数值与单位，选中轨道走主题色。两端交叉时联动，滑至外边界恢复不限，键盘可微调；范围区域使用弱分隔线，不保留数字输入框。

卡片展示名称后图鉴号、性别、稀有状态、性格与标记、蛋组、体型／声音及位置；卡片点击选择，独立详情按钮跳到背包。网格行按内容高度排列，禁止将整页卡片压缩到视口高度。选中使用主题描边和浅底，不抬升。窗口≤960px右栏移到列表下方，≤560px公母上下排列，页面与列表保留滚动。

### 智能配窝的迭代候选（F04-U5，2026-10-17，本地已实现）

完整功能与状态见BREEDING_PLANNER_SPEC和ROADMAP F04-U5。合格组合使用实线卡片及“奖牌匹配”；迭代候选使用现有`--amber`语义弱底、虚线边框、工具图标及常驻“迭代候选”文字；资料未知使用中性边框、问号及“资料不足”。三类独立分区，不只靠颜色、不将可选候选灰成禁用，也不用danger表示未达标。

母本已有婉转声、父本只有大块头且原始声音95dB时，保留父本真实大块头图标，婉转声位置显示空位与“待培养”，不得画成已获完整奖牌。声音以“95dB”为主数值；百分比可作辅助，不强制同时展示，不把原始95dB写成95%。标清亲本距参考线及“遗传范围支持/范围待验证”，不用单点均值代替遗传范围。体重候选同样展示原始体重、本物种范围位置、缺失体型牌和范围证据。缺值为“—”，不能当作0。

未覆盖目标自动展开迭代候选，但不自动带入；用户选择候选并点击“生成迭代方案/用此亲本迭代”后才参与求解。按1B/2B/3B/4A/5A/6A/7B，允许新方案减少部分未锁定合格母本以覆盖更多迭代目标，结果显示具体增减并保留原方案供返回。加入画布、被选中或锁定后琥珀虚线及文字标记持续保留；相对当前目标的合格连线实线、迭代连线琥珀虚线，其他兼容线弱化而不隐藏。结果分别显示合格与迭代数量，近似个体不进入合格覆盖和产线配齐数。自选精灵模式默认“择优参与”，未采用个体提供原因。样式只用于配窝页，不改变背包/家园原有奖牌显示。

### 双牌产线（F04-U3，2026-10-16）

沿用蛋仓的紧凑工具条、横向状态按钮与暖白卡片，以及背包固定360px的筛选／详情共享区域。移除内容区重复页标题和大块顶部设置面板；配齐数量、搜索、刷新和翻页收在列表工具条，翻页紧邻刷新按钮，底部空间全部留给列表，目标、蛋组、声音与统计条件放右栏。工具条不显示配齐进度条和百分比；刷新已有记录时保持稳定的记录文案。状态按钮、搜索及重置仅改变显示过滤，双牌目标与统计条件保持各自语义。

链卡桌面端压缩为每行五张，头像居中，蛋组与状态置顶，名称后跟图鉴编号，底部性格标签、种母／种公计数位置固定；选中使用主题描边，不抬升。状态按钮不提供“资料待补”页签，但资料不足仍在链卡状态和详情中明确显示。双牌目标用现有奖牌图标和chip，声音用segmented，图标复用UiIcon、本地Tabler及现有奖牌资源，不新增主题色表。

详情沿用家园的头像和性别描边，种母／种公共用CollectionParentCard；显示性格、结构化双标图标、原始分贝、身高／体重百分比、位置，并明确当前佩戴／数值参考；说明文字不生成图标，满身高不画成大块头。进化链横向排列，列表与详情独立滚动；打开详情不改变卡片列宽。≤960px筛选折叠到列表上方，详情使用360px右侧抽屉，支持Esc、焦点循环、背景inert和关闭后返回触发卡片；切号／离页释放模态状态。

### 家园精灵与配对关系（F04-U2-D，2026-10-16）

家园内容区展示家园精灵与配对关系。左右面板和各自列表区撑满可用内容高度，列表独立纵向滚动，标题固定在列表外；宽屏精灵卡每行三列，内容区不超过1000px时两列，620px及以下单列。卡片按自身内容高度顶对齐，不拉伸成同一行最高卡片的高度；精灵卡片不响应点击，也不能拖动排序。内容区不超过1000px时双面板上下排列。配对区最大宽度360 CSS px，在150%缩放下约540屏幕像素。布局按内容区宽度响应，不用窗口像素猜测侧栏占用。

家园精灵卡使用整圈浅粉/浅蓝性别描边、暖白表面与柔和主题色立绘背景。卡片内立绘区与信息区等高，左侧立绘容器随卡片拉伸，原图适度放大；头像下方不显示文字或产蛋信息。右侧展示姓名/稀有度图标，性别图标靠标题行右侧；不显示等级和蛋组。性格后显示大块头、小不点、婉转声、粗嗓门奖牌图标。身高、体重和声音数值以对应范围百分比显示，进度条与百分比一致，缺失值为空轨道和“—”。异色、异色炫彩图标紧跟名称；立绘复用原有游戏图片并保留透明区域，不裁切或用设计图插画替换。物种名与姓名相同时省略重复行；不同物种名保留。

每个母本独立一条配对，使用独立浅底和边框；学院绿窝配对母本组置顶，并以绿色底色和强调边框区分。母本、父本都按“标签—头像—名称”横排；父本标签只在行首出现一次，标签至首个头像的间距与母本一致。父本超长保持单行，按住鼠标可左右拖动，隐藏滚动条外观。产蛋种类、蛋重和分贝预测尽量同一行；不增加缺少真实数据来源的场景时间戳。

性格概率为双列紧凑布局，每项同一行显示名称、独立0–100%概率条与百分比；随机使用琥珀色、未知使用灰色。配对继续绑定真实场景记录，不显示范围候选入口；人数、母本数、蛋种与概率不写死为设计图示意。界面不恢复家园位置视图、概览条、搜索/刷新条或窝类型统计区块。

### 桌面标题栏

pywebview 窗口保留 Windows 原生边框样式，通过 `WM_NCCALCSIZE` 隐藏系统标题栏绘制，
保留系统最大化/还原/最小化动画；独立 `desktop-shell.css/js` 管理 40px 高的主题顶栏。
窗口消息回调在 GUI 线程安装，随窗口销毁卸载；动画遵循 Windows 的动画设置。
左侧为头像、名称与拖动区，右侧为最小化、最大化/还原、关闭；在before_show注册WebView2 NavigationStarting，在首次导航提交前启用原生非客户区支持（loaded后更改只对下次导航生效）。通过CSS `app-region: drag`承接拖动、双击和贴边吸附，不注册pywebview逐帧mousemove移动。窗口按钮区域为`no-drag`。
窗口按钮不参与拖动；八个 6px 边缘通过 pywebview 缩放并固定对边，最大化时隐藏。
原生窗口是状态权威，最大化按当前屏幕工作区避免覆盖任务栏；关闭仍走桌面壳的正常退出链。
主界面就绪后显示标题栏；启动阶段由原生面板提供关闭按钮。浏览器模式不显示窗口按钮或预留高度。
启动窗口默认1440×810逻辑像素；已有记录恢复上次手动调整的宽高和比例，按当前DPI和工作区等比缩小。窗口显示前恢复指定外框尺寸，修正WinForms切成无边框时扣掉旧非客户区大小的问题；不在加载后再次缩放。运行期间可自由改变比例。
首次启动或旧配置没有坐标时使用系统默认居中位置；正常关闭时保存正常窗口的物理坐标与逻辑尺寸。最大化/最小化退出使用还原边界，不记录最小化坐标。下次显示前恢复位置；显示器断开或工作区变化时将窗口移回最近屏幕的可见工作区，支持副屏负坐标。

### 启动遮罩

桌面窗口首次显示前安装原生面板，只显示静态本地图标与固定文案“正在启动…”，不使用转圈或循环动画。
从网页导航到 bootstrap、Vue 入口和首屏布局就绪，全程保留同一个面板；桌面URL含`desktop=1`，head阶段即隐藏网页logo，桥接延迟也不显示第二个图标。loaded只将尚未销毁的原生面板置顶，不交接另一套加载画面。
标题栏与主题应用在遮罩后完成，首屏绘制就绪后才揭开；不人为设置最低等待时间，也不显示虚构百分比。
脚本/样式/数据失败通过 JS 桥报告给同一原生面板；原生计时器只在 20 秒超时后触发提示，不进行高频绘制。
失败与重试使用固定槽位，图标和标题位置不变；重新加载恢复带登录 fragment 的原始 URL，关闭释放控件、图片、字体和计时器。
浏览器模式由 `index.html` 的内联启动样式与 `boot.js` 显示静态网页面板，固定80px图标与242px内容槽位，和原生面板使用同一布局尺寸；状态文字和重试按钮不推动图标。首屏就绪后淡出，减少动画模式直接切换。
原生底色 `run.py:SPLASH_BG` 与 HTML 默认 `--bg` 同步，避免白屏；桌面端没有可见的原生→网页加载画面切换。

### Vue 页面组件与状态矩阵（2026-10-18）

Vue 页面沿用同一套 token 与命名：组件先在页面内以类名复用，出现第二个使用方再抽 SFC（见 §4「不为单一使用方预抽象」）。配窝页（F04-U5）的**大体布局冻结**：主画布在左、目标／参与精灵在右、画布右侧为亲本索引，两列（1200px 收窄、960px 上下排列）与各区域先后顺序不变，只改组件内部表达。

| 状态 | 要求 |
|---|---|
| Default | 只用 token，不写字面 hex/rgba（1px、`999px`、`50%` 例外） |
| Hover | 仅指针设备；抬升用 `--motion-lift`，不改变尺寸或相邻项位置 |
| Active | 按压 `scale(.97)` |
| Focus-visible | `2px var(--focus-ring)`、offset 2px；不用 `outline:none` 抵消 |
| Selected | 浅底＋深字＋描边，不抬升；不只靠颜色，配图标或文字 |
| Disabled | 禁用**不用透明度**：`--surface-2` 底＋`--muted` 字（浅底上约 4.8:1，切主题需复核），语义用原生 `disabled` 或 `aria-disabled` |
| Loading | 宽度锁定不跳宽；100ms–1s 按钮内 spinner，>1s 给确定性步骤文案 |
| Error | 就地显示＋可重试操作，`role=alert`；信息与成功用 `role=status` |
| Empty | 说明为什么空＋下一步；同类空态文案一致 |
| Overflow | 长名 ellipsis＋`title`；0 项、30 目标、11 窝都不塌陷 |

反馈时间分级：<100ms 不显示；100ms–1s 按钮内 spinner；>1s 显示确定性步骤（配窝求解约 2.5s 属此档，用「搜索候选 → 评估布局 → 整理方案」）；>10s 才是后台任务。

动效统一 `--motion-fast/--motion-base/--motion-ease`（app.css:9-13），过渡只列具体属性、禁止 `transition: all`；`prefers-reduced-motion` 由 app.css:102 全局生效，页面不重复声明。

配窝页组件对应现类名：模式切换 `.planner-tabs`、主操作 `.planner-primary`（每屏至多一个）、次操作 `.ghost-button`、方案 chip `.planner-alternatives .chip`、常驻状态行 `.planner-status`（账号・只数、忙碌/待评、方案状态、目标就绪进度）、画布 `.planner-canvas` 与亲本索引 `.planner-canvas-key`、caption `.planner-canvas-caption`（连线图例与交互提示）、产物卡 `.planner-outcome`、目标卡 `.planner-goal-editor`、迭代卡 `.planner-iteration`、提示条 `.planner-notice`（`.is-error/.is-success/.is-warning`）、空状态 `.planner-empty`。画布内：窝群始终居中（硬性验收项，贴左上角即不通过），有效区 0～18 带边界，窝位序号与性别合成角标，学院窝加「学」角标，合格连线实线／干扰虚线，等待重评时隐藏旧线并标注。
