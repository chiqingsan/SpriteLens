# UI 规范（现有 web/static 与 Vue 组件）

适用范围：当前 `spritelens/web/static/` 与后续 `frontend/` Vue 工程中的全部界面工作。加新页面、改组件、调样式
之前先读这份；与 `DEVELOPMENT_GUIDE.md` 的前端约定配合使用（那边管架构与
安全转义，这边管视觉与组件）。

## 1. 参照系与设计立场

- **蛋神助手**（布局对标对象）：它的 `:root` 与我们同源，视觉密度为
  数据面板风格——保留紧凑布局，正文 14px 起、辅助字 13px、密集角标最低 13px。
  最重要的观察：**它几乎不用阴影**（大量 `box-shadow: none`），质感来自
  1px 描边 + surface 分层底色。我们也照此执行：能靠描边和底色分层解决
  的，不加阴影。
- **Open Props**（分级节奏参照）：间距 4px 步进、少档圆角的 scale 思路。
- **自然绿参考主题**：暖白 `#F6F6ED` 工作面、浅绿分组侧栏，主按钮 `#5F7D48` 配白字；
  浅绿 `#E1EC8F` 仅搭配深字。精灵立绘、色卡和系别配色保持业务含义。
- **shadcn/ui**（命名思想参照）：语义化变量命名（什么用途，而不是什么颜色）。
  我们的 `--surface-2`、`--ink-soft`、`--amber-ink` 都是这个思路。
- 前端已确认采用 Vue 3 + TypeScript + Vite；视觉 tokens、紧凑布局和离线资源约束保留。
  初期复用 CSS 变量与组件语义，不引入第二套主题体系；组件库按实际需要评估，迁移方法见 [VUE3_MIGRATION](VUE3_MIGRATION.md)。

## 2. Token 速查（颜色预设在 themes.css，布局在 app.css，禁止绕过）

侧栏切页直接显示目标页面，不做整页透明度/位移入场动画。返回页面保留内容与滚动位置，按账号、数据版本和筛选条件决定是否刷新；按钮等局部交互仍保留过渡。蛋蛋图鉴按滚动分批显示卡片，返回时复用已加载内容。

**选值规则：先查这张表，表里没有的语义先加 token 再用；禁止在规则里写
hex/rgba 字面值。** 1px 属"贴紧"语义、`999px` 胶囊、`50%` 正圆，可直接
写字面值。

| 组 | Token | 用途 |
|---|---|---|
| 间距 | `--space-0..8` = 2/4/6/8/10/12/16/20/24px | margin/padding/gap 全部走它；新增布局禁止 3/5/7/9 等奇数散值（既有邻近页卡片内衬 3/5px 是像素级折中，不据此扩用） |
| 字号 | `--fs-3xs..2xl` = 13/14/14/14/15/16/20/28px | 密集角标 → 辅助标签 → 次要信息 → 正文 → 强调正文(基准) → 区块/面板标题 → 页面标题 → 大数字 |
| 圆角 | `--radius-xs/sm/md/lg/xl` = 6/8/10/12/16px + `--radius-pill` = 999px | 极小标签/内嵌色块 → chip/输入框/小徽章 → 卡片/头像/弹层（默认） → 面板/列表容器 → 工作画布/模态框；胶囊与圆点用 pill |
| 阴影 | `--shadow` / `--shadow-pop` / `--shadow-inset`（`--shadow-hover` 已定义但无使用方） | 面板静置 → toast/浮层 → 头像内阴影；卡片悬停统一用 `--shadow-1`，不要再引 `--shadow-hover` |
| 表面 | `--surface-1..4` | 工具条底 → 常用次级底（行悬停/chip/账号行） → 更深一档（轨道/占位头像/按钮静置底） → 按压最深档 |
| 线 | `--line` / `--line-soft` | 常规边框；表格内弱分隔用 soft |
| 文字 | `--ink` / `--ink-soft` / `--muted` / `--muted-2` | 标题 → 深青正文 → 次要说明 → 占位字/徽章淡字 |
| 品牌 | `--teal` 四阶 + `--teal-bright` + `--focus-ring` + `--accent/--on-accent` | 保留变量名，映射喵喵绿/火花红/水蓝蓝蓝；浅选中背景必须搭配深字 |
| 琥珀 | `--amber` 六件套 | 处理中状态与提示条专用（`--on-amber` 是渐变底上的深字） |
| 危险 | `--danger` 四件套 + `--positive/--negative/--ok` | danger只留破坏性操作；火花主色使用独立品牌token，数值升降用positive/negative |
| 性别 | `--male/--female` + `--male-strong/--female-strong` + `--male-ink/--female-ink` | 环形标记与性别符号；精灵卡片按性别使用浅蓝/浅粉底色 |
| 侧栏 | `--sidebar-bg/text/muted/line/hover` + `--selection-mark` | 浅绿底、文字、分隔、悬停与选中标记；`--deep-*` 保留给深色业务表面 |
| 图表 | `--chart-v`（未定义，取值回退 `--teal`） | 声量条颜色；`.measure-voice` 用 `var(--chart-v, var(--teal))`。`--chart-h/--chart-w` 与 `.body-bar` 已删除，不要恢复 |

业务色（系别/天赋阶/glass 渐变）不属于 CSS token：由 `domain/display.py`
经 payloads 下发，前端不复制色表（见 DEVELOPMENT_GUIDE）。

### 字号执行规则

- 所有页面文字必须使用字号 token，不在页面 CSS 中写新的 `px` 字号。
- `--fs-3xs`（13px）是全应用密集信息的下限；正文和可操作文字使用
  `--fs-sm`（14px）或更大字号。禁止用 12px 及以下字号承载可读文字、按钮、筛选项、
  状态或地图/雷达标签。
- 徽标、图表和 SVG 内文字同样遵守下限；如果放大后空间不足，应扩大容器或调整布局，
  不得重新缩小字号换取不溢出。数字、实体编号等紧凑信息也只能使用 `--fs-3xs`，
  不得恢复硬编码小字号。

### 三主题与偏好

`themes.css`默认喵喵，`data-theme=huohua/shuilanlan`覆盖色值；共用浅色布局。
`appearance.js`只更新根样式/显示类，不重建数据；设置页三枚主题名称按钮立即应用，不使用精灵图片。宽屏为说明与按钮的紧凑设置行，窄屏上下排列。
`ui.preferences`仅保存theme、pet_view、fields，经鉴权`GET/POST /api/ui/preferences`读写，bootstrap恢复。
非法配置回默认，非法提交400；原子写入失败500，UI保留预览并明确提示失败。
蛋组/数值/业务筛选不跨启动保存；显示选项不影响筛选计数。

### 本地图标

应用品牌标识使用好奇版绿色头像（`resources/icon_source.png`）：微歪头、大椭圆眼睛高光、眼底绿色亮面与短 W 形嘴；以 16/24/32px 的辨识度检查眼神。
经 `tools/make_icon.py` 派生窗口/任务栏 ICO 和 `favicon.png`；浏览器标签页与侧栏品牌标识复用后者。

优先Tabler官方outline，缺语义再Lucide。`icons/*.svg`及sprite为24×24、2px圆角描边、currentColor。
`icons/sources.json`记录版本/URL/许可/搜索标签，MIT全文在`icons/LICENSE.txt`。
`tools/sync_ui_icons.py`只在开发导入时联网；`icons.js`装饰导航/控制/空状态，图片和性别符号保持原样。
六维性格方向使用本地Tabler `arrow-up` / `arrow-down` 图标，笔画为2.5px；属性文字与方向图标放在同一SVG组并垂直居中。属性数值为0的天赋加成省略，非零加成紧随当前值显示。
伙伴标记只在精灵背包点阵顶行只读显示，顺序固定为「性别 → 伙伴标记 → 稀有/色卡标记 → 性格」，不提供设置/编辑入口。整体尺寸绑定 `ui.css` 的 `.pet-partner-mark`（18×18，内层图标 62%）；`spritelens/web/static/partner-marks/frame.webp` 只允许包含贴纸本体，**不得烘焙半透明黑色投影**——`rgba(0,0,0,~0.2)` 叠在浅色卡片 `rgb(255,240,244)` 上会合成 `rgb(204,191,194)` 的灰色描边，视觉上像多了一圈边框（2026-10-24 事故）。替换资产后必须在真实数据卡片上放大目视复核，不能只看构建或单张合成图。
滚动条默认隐藏外观，overflow不变；导航也适用，不重新设置thin。背包游戏箱的 `.table-wrap` 是明确例外，必须保留可发现的原生横/纵滚动条，不能用隐藏滚动条掩盖 6×5 点阵的最小宽度溢出。蛋仓列表 `.eggbox-list-scroll` 是第二个例外（2026-10-28 用户要求）：`scrollbar-width: thin` + `scrollbar-gutter: stable` + 8px `::-webkit-scrollbar`，滑块 `color-mix(in srgb, var(--line) 80%, transparent)`、悬停 `var(--teal-bright)`；槽位恒定预留 8px，避免是否滚动导致卡片列宽抖动。

### 精灵蛋仓

蛋仓沿用三主题，桌面按约 2:1 分为列表与详情。工具栏将缓存状态、点击切换升/倒序的按钮和搜索放在同一行；两种顺序用箭头、边框和底色区分，类型筛选铺满下一行。
列表卡片使用统一竖向比例，依次展示蛋图与名称、单行标签、尺寸/重量和获得时间；有无标签都保持相同尺寸和数据行位置。普通窝在左上角显示灰色胶囊，学院绿窝显示绿色胶囊，无窝标签时不显示；收藏按钮位于右上角，真实在孵状态和堆叠数量保留角标。
卡片最小高度为240px，顶部角标行至少保留24px，无角标也不塌陷；蛋图与名称整体上移20px，标签行上移8px以缩短上沿留白并保留组内间隔；异色蛋名称尾部显示1em异色标识（`/static/rarity/shiny-fit.webp`，`alt`/`title` 为「异色」），炫彩蛋同位置显示1em炫彩标识（`/static/rarity/colorful-fit.webp`，「炫彩」），两者都紧贴名称、间隔6px，`egg_kind` 单值所以不会同时出现（2026-10-28）；卡片内容行间距为4px，名称下移4px、数据区上移4px以收紧名称/标签/数据区之间的留白，底部尺寸/重量与日期行间隔6px。
性格使用浅绿标签，声音使用浅紫标签，体型奖牌使用浅金标签；四枚标签时收紧间距，保持单行。无其他标签时显示“一颗充满活力的精灵蛋，正等待新的冒险。”，仅有窝标签时也显示该文案。列表按可用宽度使用一至五列，保持卡片文字可读；选中使用主题描边与浅底，不抬升卡片。
列表自身显示主题细滚动条（8px 滑块、透明轨道、`scrollbar-gutter: stable` 预留槽位，见上文例外条款；2026-10-28 用 20 枚合成蛋在 1440×1000 与 520 宽真实 Edge 渲染确认槽位占用 8px、内容不横向溢出、卡片列宽不被挤压）；卡片按批次渐进挂载，滚近底部再追加，筛选和排序变化时从顶部开始新批次。蛋图使用浏览器原生图片懒加载并异步解码。
详情包含蛋图/名称/蛋组、标签状态与编辑、数据对比和孵化记录；未知范围显示占位，超界仍保留实际值并明确标记。性格可在蛋仓手动选择；蛋窝默认为自动，家园拾蛋默认为普通窝，允许改为学院绿窝。
重量极值在目录范围端点的误差不超过整个范围宽度0.1%时自动显示；大块头/小不点沿用精灵标记的2%范围规则。声音标签可在蛋详情手动选择；手动分贝输入同样位于蛋详情，范围为−100到100的整数，只记录这枚蛋，不改写精灵抓取声音。
尺寸与重量复用本地 Tabler `ruler-2`、`weight`，与时钟/排序图标保持同一描边风格。性格、蛋窝、声音标签和手动分贝按账号与蛋实例持久化。

### 筛选配对（F04-U4，2026-10-16）

沿用暖白卡片、性别描边、性格chip、本地奖牌图和UiIcon。主区父本／母本双栏，各自滚动和分页，每侧最多24只；翻页控件紧邻列头的选择提示，列表占满列头以下空间。顶部搜索、性格一致与刷新保持紧凑。右侧固定360px（较窄桌面320px），持续显示筛选设置，列表宽度保持稳定。筛选多项奖牌同时满足，蛋组／性格同组内任选。声音、身高和体重复用DualRangeSlider双头滑条，声音−100～100dB、体型0～100%；每行左侧名称、右侧当前范围摘要，底部两端显示数值与单位，选中轨道走主题色。两端交叉时联动，滑至外边界恢复不限，键盘可微调；范围区域使用弱分隔线，不保留数字输入框。

卡片分三段：身份行（性别浅底立绘 + 名称／图鉴号／稀有徽章／性别符号，第二行性格 chip 与奖牌，第三行蛋组）、三列数据带（高／重／声，细线分栏、数值加粗、越界值走琥珀色）、位置与详情底栏；卡片点击选择，独立详情按钮跳到背包。稀有状态使用家园卡同款透明徽章，不再占独立文字行。网格行按内容高度排列，禁止将整页卡片压缩到视口高度。选中使用主题描边和浅底，不抬升，选中圆勾压在立绘左上角。卡片按自身宽度（容器查询）降级：≤340px 缩小立绘，≤300px 数据带标签移到数值上方、奖牌允许折行且列头辅助提示让位，保证性格标签不被压成竖排、三列读数不被截断。窗口≤960px右栏移到列表下方，≤560px公母上下排列，页面与列表保留滚动。2026-10-28 在 1440×900、1280×800、960×700、700×700（DPR2）及注入最长名称／全奖牌／超界读数的极限卡片上用 Edge 真实渲染复验：无横向溢出、无元素越界、无互相遮挡。

### 智能配窝的迭代候选（F04-U5，2026-10-17，本地已实现）

完整功能与状态见BREEDING_PLANNER_SPEC和ROADMAP F04-U5。合格组合使用实线卡片及“奖牌匹配”；迭代候选使用现有`--amber`语义弱底、虚线边框、工具图标及常驻“迭代候选”文字；资料未知使用中性边框、问号及“资料不足”。三类独立分区，不只靠颜色、不将可选候选灰成禁用，也不用danger表示未达标。

母本已有婉转声、父本只有大块头且原始声音95dB时，保留父本真实大块头图标，婉转声位置显示空位与“待培养”，不得画成已获完整奖牌。声音以“95dB”为主数值；百分比可作辅助，不强制同时展示，不把原始95dB写成95%。标清亲本距参考线及“遗传范围支持/范围待验证”，不用单点均值代替遗传范围。体重候选同样展示原始体重、本物种范围位置、缺失体型牌和范围证据。缺值为“—”，不能当作0。

未覆盖目标自动展开迭代候选，但不自动带入；用户选择候选并点击“生成迭代方案/用此亲本迭代”后才参与求解。按1B/2B/3B/4A/5A/6A/7B，允许新方案减少部分未锁定合格母本以覆盖更多迭代目标，结果显示具体增减并保留原方案供返回。加入画布、被选中或锁定后琥珀虚线及文字标记持续保留；相对当前目标的合格连线实线、迭代连线琥珀虚线，其他兼容线弱化而不隐藏。结果分别显示合格与迭代数量，近似个体不进入合格覆盖和产线配齐数。自选精灵模式默认“择优参与”，未采用个体提供原因。样式只用于配窝页，不改变背包/家园原有奖牌显示。

### 双牌产线（F04-U3，2026-10-16）

沿用蛋仓的紧凑工具条、横向状态按钮与暖白卡片，以及背包固定360px的筛选／详情共享区域。移除内容区重复页标题和大块顶部设置面板；配齐数量、搜索、刷新和翻页收在列表工具条，翻页紧邻刷新按钮，底部空间全部留给列表，目标、蛋组、声音与统计条件放右栏。工具条不显示配齐进度条和百分比；刷新已有记录时保持稳定的记录文案。状态按钮、搜索及重置仅改变显示过滤，双牌目标与统计条件保持各自语义。

链卡桌面端压缩为每行五张，头像居中，蛋组与状态置顶，名称后跟图鉴编号，底部性格标签、种母／种公计数位置固定；选中使用主题描边，不抬升。状态按钮不提供“资料待补”页签，但资料不足仍在链卡状态和详情中明确显示。双牌目标用现有奖牌图标和chip，声音用segmented，图标复用UiIcon、本地Tabler及现有奖牌资源，不新增主题色表。

详情沿用家园的头像和性别描边，种母／种公共用CollectionParentCard；显示性格、结构化双标图标、原始分贝、身高／体重百分比、位置，并明确当前佩戴／数值参考；说明文字不生成图标，满身高不画成大块头。进化链横向排列，列表与详情独立滚动；打开详情不改变卡片列宽。≤960px筛选折叠到列表上方，详情使用360px右侧抽屉，支持Esc、焦点循环、背景inert和关闭后返回触发卡片；切号／离页释放模态状态。

### 家园精灵与配对关系（F04-U2-D，2026-10-16）

家园内容区展示家园精灵与配对关系。左右面板和各自列表区撑满可用内容高度，列表独立纵向滚动，标题固定在列表外；宽屏精灵卡每行三列，内容区不超过1000px时两列，620px及以下单列。卡片按自身内容高度顶对齐，不拉伸成同一行最高卡片的高度；精灵卡片不响应点击，也不能拖动排序。内容区不超过1000px时双面板上下排列。配对区最大宽度360 CSS px，在150%缩放下约540屏幕像素。布局按内容区宽度响应，不用窗口像素猜测侧栏占用。

### Vue 页面组件与状态矩阵（2026-10-18）

Vue 页面沿用同一套 token 与命名：组件先在页面内以类名复用，出现第二个使用方再抽 SFC（见 §4「不为单一使用方预抽象」）。配窝页（F04-U5）的**大体布局冻结**：主画布在左、目标／参与精灵在右、画布右侧为亲本索引，两列（1200px 收窄、960px 上下排列）与各区域先后顺序不变，只改组件内部表达。

| 状态 | 要求 |
|---|---|
| Default | 只用 token，不写字面 hex/rgba（1px、`999px`、`50%` 例外） |
| Hover | 直接 `:hover`（当前未做指针设备媒体查询隔离）；抬升用 `--motion-lift`，不改变尺寸或相邻项位置；触屏确认不能依赖悬停态 |
| Active | 按压 `scale(.97)` |
| Focus-visible | 全局 `2px` 实线、颜色为 `--focus-ring` 60% 混合（app.css:165）、offset 2px；局部可显式用纯 `--focus-ring`；不用 `outline:none` 抵消 |
| Selected | 浅底＋深字＋描边，不抬升；不只靠颜色，配图标或文字 |
| Disabled | 禁用**优先不用透明度**：`--surface-2` 底＋`--muted` 字（浅底上约 4.8:1，切主题需复核），语义用原生 `disabled` 或 `aria-disabled`；遗留 `.ghost-button:disabled` 仍是 `opacity:.45`（app.css:481），改动该组件时一并收敛 |
| Loading | 宽度锁定不跳宽；100ms–1s 按钮内 spinner，>1s 给确定性步骤文案 |
| Error | 就地显示＋可重试操作，`role=alert`；信息与成功用 `role=status` |
| Empty | 说明为什么空＋下一步；同类空态文案一致 |
| Overflow | 长名 ellipsis＋`title`；0 项、30 目标、11 窝都不塌陷 |

反馈时间分级：<100ms 不显示；100ms–1s 按钮内 spinner；>1s 显示确定性文案（配窝求解属此档，但现实现只区分 `loading`/`saving` 两个状态并显示「正在生成方案」类文案，没有分步步骤提示）；>10s 才是后台任务。

动效统一 `--motion-fast/--motion-base/--motion-ease`（另有 `--motion-slow/--motion-ease-in-out/--motion-spring/--motion-lift`，定义见 app.css:12-18），过渡只列具体属性、禁止 `transition: all`；`prefers-reduced-motion` 由 app.css:169 全局生效，页面不重复声明。

硬性规定：规划期间不得出现 UI 跳动。工具条、状态行、画布与结果区的**位置与尺寸**在「点击生成」到「结果返回」之间不得变化：按钮标签变化不得改变按钮宽度（改变标签的按钮设固定宽度并把标签居中、标签统一四字），进度与提示只能占用已预留区域（状态行最小高度、caption 最小高度；提示条保持流内、只在用户操作或结果返回之后更新（右下角消息总线式 toast 属未排期设计，当前页面不做浮层提示），滚动区用 `scrollbar-gutter: stable` 保留滚动条占位），不得用出现/消失的内联文案挤动相邻元素，也不得在规划开始时清空提示条把画布顶下/顶上；提示条只在用户操作或结果返回之后更新。同理，禁用原因只在 `title` 表达，不做占位提示。

配窝页组件对应现类名：模式切换 `.planner-tabs`、主操作 `.planner-primary`（每屏至多一个）、次操作 `.ghost-button`、方案卡 `.planner-outcome-list > .planner-outcome`、常驻状态行 `.planner-state`（`.planner-state-badge` / `.planner-state-metric` 表达账号・只数、忙碌/待评、方案状态、目标就绪进度）、容量卡 `.planner-capacity`（左示意图位 `.planner-capacity-art`、`普通小窝` 标签＋计数步进器 `.planner-stepper`（`−` / `.planner-stepper-value` / `+`，普通小窝上限 10，到界禁用对应按钮）、学院绿窝勾选框 `.planner-capacity-academy`（视觉隐藏的 `input[type=checkbox]` + 自绘 `.planner-check` 方格与对勾，`.planner-capacity-cap` 圆形绿底毕业帽，当前始终显示（无媒体查询隐藏；若要在 ≤1200px 隐藏需先补规则））、底部 `.planner-capacity-total` 用大号数字给出本次规划容量；勾选框与步进按钮必须保留键盘可达与 `:focus-visible` 焦点环，不得只画一个 div）、画布 `.planner-canvas` 与亲本索引 `.planner-canvas-key`、caption `.planner-canvas-caption`（连线图例与交互提示）、产物卡 `.planner-outcome`、目标卡 `.planner-goal-editor`、迭代卡 `.planner-iteration`、提示条 `.planner-notice`（`.is-error/.is-success/.is-warning`）、空状态 `.planner-empty`。画布内：窝群始终居中且足够大（硬性验收项：贴左上角、或小到看不清即不通过；画布元素为正方形，视口随窝群自适应，小窝群视口不小于 400 单位），有效区 0～18（拖动与方向键已夹取该范围，网格铺满画布），窝位序号与性别合成角标，学院窝加「学」角标，合格连线实线／干扰虚线，等待重评时隐藏旧线并标注。

### 工具条单行与折行规则（2026-10-28，强制）

状态：全项目强制规范，2026-10-28 起执行。读者：前端实现者、代码复核者与验收者。维护范围：常驻面板内工具条的宽度分配、折行与断点。以背包工具条为基准实现，其他页工具条用同一方法先算面板宽度再定断点。

- **先算面板宽度，不要用窗口宽度做布局判断。** 背包页与非附近页的侧栏在页内被收成 64px（`ui.css:454-455` 的 `:root:has(#page-pets.active)`），面板 ≈ 窗口 − 64px 侧栏 − 360px 常驻筛选栏 − 16px 内边距；默认侧栏是 216px（`app.css:88`），换算时按当前页实际值算。`backpack-layout.css` 里任何按窗口写的 `@media` 都必须换算成面板宽度并把算式写进注释（现行：58–107 行）。
- **单行是默认目标，宽度不足时按顺序让宽，不得以「允许换行」作为溢出解法：**①唯一可伸缩项（搜索框）先缩，下限 `min-width: 5.5em`；②低信息量文本随后收起——命中徽标在窗口 ≤1479px 只留数字（`1930 / 1930`），「排序」二字在 ≤1421px 收起并收紧各控件内边距。
- **折行是最后的降级，只在面板物理放不下时启用**（背包为窗口 ≤1348px，面板约 700px 以下）。折行结构固定为「控制行 + 搜索/命中独占整行」：搜索行左对齐、与首行左缘对齐，不允许内容被推到行尾；内层容器不得用 `flex:1` 撑满整行再把内容靠右。
- **工具栏高度只允许随断点分档（背包实测 51 / 93 / 135px；CSS 里没有硬编码高度，靠内容与断点自然分档），不得随数据、文案或加载状态变化。** 命中徽标按数字位预留宽度（`calc(3em + 13ch + 2 * var(--space-3))`），只更新文字，宽度不变、不推动相邻控件。
- **禁止在 `flex-wrap` / `flex: none` 之间反复翻转。** 这段规则历史上被改过三次（允许换行 → 固定单行 → 再允许换行），直接造成工具栏在 51/93/135px 之间跳、徽标被挤出面板右缘 68px 后被裁。
- **验收按断点边界逐档执行：**1600 / 1490（用户实际窗口，DPR 1.5）/ 1480 / 1479 / 1422 / 1421 / 1400 / 1366 / 1349 必须单行（`51px`），命中徽标右缘等于工具栏内容右缘；1348 / 1200 / 1024 检查折行结构与左对齐；全部要求 `scrollWidth == clientWidth`、徽标不被裁切、不伸到右侧筛选栏下方。只截一张窗口图不能作为验收依据。
- **改工具栏前先算自然宽度合计**（当前五组控件约 986px：视图 222 + 搜索 225 + 显示设置 78 + 排序 255 + 徽标 170 + 间隙 24×3 + 内边距 16），再决定让哪个控件；不得靠缩小字号、删除功能或裁切换取单行。

## 数据更新不得造成 UI 闪动

状态：全项目强制规范，2026-10-24 起执行。读者：前端实现者、代码复核者与验收者。维护范围：后台数据更新的视觉稳定性及动态验收；以下根因已于 2026-11 按本规则改造完成，本节记录现行机制与历史事故，真实 WebView2 动态验收仍需按验收条目复核。

### 附近页刷新区：现行机制与历史根因

截图框选的是排序与刷新工具区。**2026-11 现行实现**：`useNearby.ts` 的 `update()` 只做摘要比较，随后走 `autoLoadSoon()`（`AUTO_LOAD_INTERVAL_MS=500` 合并），后台同步不进 `loading`；`loading` 只覆盖首次读取与手动刷新。`NearbyPage.vue` 的刷新按钮由局部 `refreshing` 驱动、文案固定为“刷新”，列表的 `aria-busy` 才用 `loading`。因此不再出现按钮反复变灰、两字↔三字文案切换或工具栏换行位置变化。历史事故保留为反面案例：一旦用后台请求驱动 `loading`，就会连带 `.ghost-button:disabled` 的 `opacity:.45` 与可换行 flex 造成视觉闪动；颜色/透明度变化即使没有尺寸变化也属闪动，截图本身不能给出闪动频率。

同页虚拟列表（2026-11 现状）：`watch(rows)` 按可见卡锚点补偿（`getOffsetForIndex` + `scrollToOffset`，保留测量缓存），只有搜索、排序、归属（uid / 观察周期）变化时才回到顶部；普通实时增删不再重置阅读位置与测量结果。历史实现曾在任意 `rowKeys` 变化时无条件 `scrollTop=0` 并全量 `measure()`，属已修复的独立问题。

### 实现要求

- 请求进行中是传输状态，不能直接作为整页视觉加载状态。分别表达首次加载、手动刷新和后台同步；后台同步保持操作区文案和视觉样式稳定，只有数据就绪时提交变化。并发合并、取消及旧响应失效继续由请求所有者处理，按钮不因每个后台请求反复禁用；手动刷新需要防重复时只关联手动操作状态。
- 首次没有内容时可以显示加载态；同账号、同观察周期的后续请求保持旧内容，失败保留旧结果并提供可读错误。切号、切场景、断线等真实归属失效按业务契约清空，不能为视觉稳定继续显示错误归属的数据。
- 需要切换的按钮文字、计数、时间与状态区预留合理空间；按钮宽度应覆盖最长状态文案，并验证窄屏/缩放。焦点、选中和禁用不改变几何尺寸；不能只加固定宽度而保留后台禁用导致的明暗闪烁。
- 使用稳定业务 ID 作为实体 key；禁止用时间戳、数据版本或请求序号让整个内容区反复卸载重建。只在真实业务周期切换时重置归属。保留相同来源的图片节点，避免反复重载头像。
- 虚拟列表在数值更新及普通增删时保留当前可见实体和滚动锚点；删除锚点时选合理相邻项。仅用户明确改变搜索/排序或进入新业务周期时按设计重置。尺寸实际变化才更新对应测量，禁止每次数据刷新清空全部测量缓存。
- 提示、徽章及错误区出现/消失不得意外推动其他操作区；用明确的占位、局部滚动或固定区域设计处理。不要以隐藏错误、关闭必要交互状态、无依据裁切或堆叠防抖延迟掩盖问题。

### 动态验收

至少覆盖正常数据和极限数据，并连续观察多轮更新：快速响应、跨多个绘制帧的慢响应、请求失败与重试、推送频率高于请求完成频率、字段变化、实体增删、滚动中更新、手动刷新，以及切号/切场景。覆盖最小支持窗口、窄屏、150%/200% 缩放、长名称、最多标签、缺图、空态和字体回退。

通过条件：后台更新不让刷新按钮反复明暗切换或换字，不让工具栏位移/换行；同归属内容不闪空；列表可见实体、阅读位置、焦点和选中保持合理连续；真实失效清空及错误仍正确展示。用浏览器自动化记录更新前后按钮文字、disabled、透明度、几何位置、滚动锚点及节点身份，并结合连续画面目视检查；单张截图、DOM 单测或构建通过不能替代此验收。记录实际覆盖、发现的问题和未验证范围，未动态复验不得宣称“无闪动”。
