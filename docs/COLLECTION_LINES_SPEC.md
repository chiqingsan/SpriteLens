# 产线收集实施规格

本轮仅研究，保留占位页。下一轮以单账号离线收集清单为第一版，复用配窝的静态兼容候选；真实产线关系在协议验证后接入。

## 1. 已验证的竞品行为

来源：蛋神助手电脑版v1.1.6 `webui/collection-lines.js`、`collection-model.js`。

- 以进化链聚合目录，建立baseId/名字/eggKey到链的索引；链成员按stage、dexNo排序。季节新增成员也计入目录，不硬编码屏蔽“未上线”链。
- 有全部/已收集/缺种公/未收集状态标签，蛋组和关键词过滤；链卡展开父母候选和账号来源，顶部进度以链为单位。
- 目标将体型与声音trait标签组合；附加设置包含only100Db、onlyMinus100Db、onlyColorful、onlyFullWeight、ignoreMissingMale、calculateGreenNest。
- +100dB和−100dB互斥；原始dB精确比较。满体重依据百分比字段，炫彩使用显式标志/变异位，不靠图像颜色。
- UI将目标与选中状态保存到本地，用户账号备注优先于自动学习名称。竞品有多账号数据来源，SpriteLens首版不引入云账号。

## 2. 口径与默认值

默认目标“基础产线”：拥有同链至少一只已知可繁育种母，且当前账号存在蛋组兼容种公。只计当前账号现有精灵，蛋仓另作“候选子代/孵化中”提示，不计为已完成。图鉴曾拥有、历史放生和同链蛋不能替代现有父母。

| 配置 | 默认 | 限制 |
|---|---|---|
| 账号 | 当前账号 | 不允许跨账号直接配对；历史账号单独查看 |
| 目标链 | 目录中确认可繁育且蛋映射已知的链 | 可勾选子集；未确认记录列为资料待补 |
| 声音 | 不限 | 可选仅+100或仅−100，互斥；原始dB |
| 满体重 | 关闭 | 开启要求有效物种范围且实际值==上限；越界不算满体重 |
| 炫彩 | 关闭 | 开启需明确业务标志；当前字段未验证则禁用并解释 |
| 学院窝计算 | 关闭 | 权威窝字段/规则验证前不可开启 |
| 忽略缺种公 | 关闭 | 开启时口径变为“种母收集”，标题和分子同步改变 |

极大/极小体型与音色trait目标留后续：当前范围位置不是奖牌或遗传trait，不能据此生成标签。保留竞品目标名称作为研究项，不把未知trait算成false或已完成。

## 3. 链身份与数据契约

独立 `domain/collection_lines.py` 与 `services/collection_lines_service.py`，不从前端推导收集状态。

链key由已验证chain_members的稳定ID集合排序归一；优先egg_key作为蛋链关联；同蛋不必然同进化链。缺链记录返回独立species键并标unknown，不用名字合并。成员映射冲突列到gap并排除分母，等待修正；保留用户勾选时的目录版本。

输入：账号uid、目标配置、选中chainKeys、宠物快照/蛋仓版本、目录版本、可选配窝版本。宠物字段：gid/baseId/gender/eggGroups/breedable/height/weight/voice/已验证trait。蛋字段：instanceId/eggConfId/petConfId/quantity/hatching/obtainedAt；实际父母关联是独立可空证据字段，不能按获得时间猜。

输出：`{uid,ruleVersion,inputVersion,goal,totals:{eligible,complete,missingMale,missingFemale,unknown},lines:[{chainKey,members,eggKey,status,complete,mothers,fathers,pairs,eggs,gaps,evidence}]}`。父母引用uid+gid；pairs明确为“静态兼容候选”，不是实际父母。证据包含source、timestamp、version、confidence类别（observed/static/unknown），不捏造数值置信度。

## 4. 判定和计数

对选中有效链逐条检查目标trait，得到符合目标的种母与兼容种公。二者齐全complete；仅母存在missingMale；无母missingFemale；关键目录/trait缺失unknown。若存在一对已知合格组合则complete，即便其他同链个体资料不足。零目标链进度显示“未选择目标”，不显示100%。

分母=选中的已验证可繁育链数，分子=complete数；每条链最多贡献1，进化形态与多个蛋/个体不重复计数。unknown单独计数，不能被搜索/状态过滤偷偷移出分母。关键词、蛋组、状态标签只影响可见列表；重置显示过滤不重置目标。ignoreMissingMale开启按合格种母计数，并标“种母已收集”。

蛋仓数量按instanceId去重后加quantity；孵化中数量单列。当前蛋仓是累积观察，缺少权威删除对账时不能显示“此刻仍持有”的确定结论。待验证蛋仓全量分页边界/删除事件后再转实时库存。

## 5. 页面与状态更新

顶部目标卡、已完成/总链与缺口，中心链卡，右侧链详情：按进化阶段展示成员、现有父母、兼容组合、蛋参考范围、相关蛋、缺口操作。父母可点击背包详情；缺口文字指向明确条件（如有种母但没有同账号兼容蛋组种公）。不提供未经验证的遗传概率或“必出”结论。

更新键 `(uid,petVersion,eggVersion,catalogVersion,goalHash)`；单次计算使用一致快照。捕获/放生/移动/孵化/切号后重算；无法确认移除时标陈旧，保留历史证据。切号立即隔离数据并关闭详情。用户目标保存到独立按uid配置；显示筛选本轮业务习惯不跨启动保存。失败保留旧结果并标时间与错误，避免旧进度冒充新结果。

## 6. 前置缺口与待验证假设

已具备：物种/链静态数据、477个物种蛋关联、宠物性别/性格/声音/体型、蛋仓条目、家园 `instanceId→gid` / `baseId→物种` 关联、`layEggCouples` 与已识别增量解析；家园页的过期关系候选按巢穴范围/蛋组推导。待补：可繁育标记完整性、trait与变异字段、真实游戏帧回放确认、该规则接入产线/规划、新旧蛋库存对账、父母与产蛋实例证据。

待验证：母本链决定产物、同trait父母遗传概率、学院窝加成、跨形态继承、蛋能否替代种母目标、−100/+100规则、越界体型合法性。未经验证时页面给unknown与原因，不能使用竞品百分比作为事实。

## 7. 开发顺序与验收

先补可繁育/链冲突清单→纯domain聚合及状态→鉴权GET API→页面和按uid目标仓库→版本推送→真实协议证据。配窝服务可调用同一兼容判定，避免两个页面口径分叉。

测试：跨进化形态只计1链；同名不同ID不合并；蛋数量不进完成分子；母无公/公无母/未知trait；精确±100互斥；满体重用物种上限而非结果最大；越界不算满；筛选不改总进度；ignoreMissingMale切换标题及分子；空目标；目录冲突unknown；切号隔离；版本改变重算；孵化/放生状态；保存重启与写入失败。实际遗传结论需真实帧与游戏操作验证。
